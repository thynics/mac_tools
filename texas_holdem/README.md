# River Club · 单机德州扑克

完全离线的不限注德州扑克小游戏。macOS 原生窗口承载本地 WebKit 页面，也可以直接双击 `web/index.html` 在浏览器游玩，无需安装前端依赖或启动服务器。

## 开始游戏

```sh
./build.sh
open "build/River Club.app"
```

构建需要 macOS 的 Xcode Command Line Tools。生成当前 Mac 架构的应用，使用本地临时签名，不依赖网络。没有 Apple 开发者公证；跨机器传输后系统可能提示确认来源。

## 玩法

- 自定义总人数，包含玩家本人；每人初始 1,000 筹码。
- 每桌 2–9 人，更多玩家自动分桌，所有牌桌采用同一套规则和 AI，每手结束后平衡座位。输入人数无产品上限，实际规模取决于机器内存和模拟时间。
- 10 / 20 起始盲注，每 8 手升级。你的筹码归零即游戏结束，赢得所有筹码即夺冠。
- 支持四条街下注、最小加注、短额全押的加注权、未跟注退款、主池 / 边池、平局分池、余数筹码和单挑盲注位置。所有筹码均为整数，结算检查总量守恒。
- 加注输入为“本轮累计下注至”，可选半底池、底池、全押；`F` 弃牌，空格过牌 / 跟注。可切换 NPC 速度和可选音效。
- 自动保存到当前应用 / 浏览器的本机存储；关闭后选择“继续上次的牌局”恢复。保存发生在每次行动后和每张旁桌结算后。旁桌未完成的当前一手会在恢复后重新模拟，已结算的旁桌不会重复结算。浏览器版和应用版使用各自的存储。

## NPC 决策

六种策略风格：均衡专家、位置猎手、价值大师、施压高手、范围分析师、短码专家。它们共享相同决策能力，以紧度、侵略性、诈唬频率体现不同风格。

1. 翻牌前使用起手牌强度、同花 / 连张、位置、多人压力、跟注价格、有效筹码构建继续范围。
2. 翻牌后从未知牌池抽样，对手范围按公开投入筹码加权，估算获胜 / 平分比例。主桌每次 240 次，旁桌每次 180 次抽样。
3. 对比胜率与可争取底池对应的赔率；结合价值下注、位置、短筹码全押和基于公开弃牌率的混合诈唬决定动作。
4. AI 仅访问自身底牌和公开信息，不读取其他底牌或实际牌堆。复盘信息在一手结束后展示。

这是启发式与蒙特卡洛抽样策略，不是 GTO 求解器或竞技级扑克机器人。没有真实货币、联网对战或付费功能。

## 验证

```sh
node --test tests/engine.test.js
```

覆盖牌型 / 踢脚、7 选 5 交叉检查、盲注位置、完整与不足额加注、累计短额全押、边池、分池、隐藏信息隔离，以及 2,000 手随机动作筹码守恒和终止检查。浏览器集成测试使用 Playwright，见 `tests/browser.test.js`，设置 `NODE_PATH` 后执行。

## 文件

- `web/engine.js`：纯 JavaScript 规则引擎，可在 Node 中直接测试。
- `web/ai.js`：范围 / 抽样胜率与决策。
- `web/app.js`：赛程、分桌、交互和本地保存。
- `web/index.html`、`web/style.css`：中文界面，支持窄屏和键盘操作。
- `native/Main.swift`、`build.sh`：本地 macOS 应用外壳与打包。
